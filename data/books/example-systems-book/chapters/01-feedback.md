# Feedback

The chapter explains that systems often behave in loops rather than straight lines. A **reinforcing loop** amplifies an initial change, while a **balancing loop** pushes the system back toward a target or constraint. Readers often notice the visible event and miss the feedback structure that generated it.

## Reinforcing loops

A reinforcing loop grows because each effect becomes an input to the next round. For example, a product with more users may attract more complements, which then attract even more users. The mechanism matters more than the anecdote: growth continues only while the loop keeps creating a stronger next step than the one before it.

## Balancing loops

A balancing loop works differently. It compares the current state with a desired state and then produces a corrective response. This means the same policy can look weak at first and strong later, because the gap that triggers action changes over time. The chapter warns that analysts should not interpret every slowdown as failure; sometimes the slowdown is evidence that a balancing loop is doing its job.
